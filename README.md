# Cebuano Doctor

A local Cebuano healthcare chatbot that uses Gemma 4 for Cebuano-English translation and MedGemma for medical responses.

## How It Works

Cebuano Query → Gemma 4 → MedGemma → Gemma 4 → Cebuano Response

## Built With

- Python
- Ollama
- Gemma 4
- MedGemma
- Tkinter

## Run

Make sure Ollama and the required models are installed, then run:

```bash
python main.py
